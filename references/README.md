# References (não é produção)

Material de **inspiração e pesquisa**. Agentes e build de produção **não** devem depender destes arquivos.

| Pasta | Conteúdo |
|-------|----------|
| `inspiration/` | Sites de referência (ex.: dump Heimdall Power) |
| `raw/` | Prints, vídeos baixados, colagens |

## Regras

1. Não linkar paths de `references/` em `pages/`
2. Extrair ideias (layout, motion, hierarquia) e **reimplementar** com o design system Lector
3. Se algo virar asset oficial, copie curado para `assets/media/<slug>/` ou `assets/brand/`
